# Log filtering (Stuff A Sock In It)

`config/sasit.cfg` → `BasicFilter` drops any log event whose `"[logger]: message"` text contains one of its lines; stack traces attached to the event go with it. Scope each filter to a mod or namespace (e.g. `Parsing error loading built-in advancement farmersdelight:`) so new mods' errors stay visible.

- The filter is installed at sasit's own `FMLConstructionEvent`, so anything logged earlier can't be filtered: coremod/CleanMix messages and FML's "expecting signature … no signature matching" warnings always show.
- Universal Tweaks' `Mute Advancement Errors` does **nothing** under Cleanroom: UT's `UTForgeHooksMixin` wraps `Logger.error(String, Throwable)`, but Cleanroom's `ForgeHooks.lambda$loadAdvancements$0` calls `error(String, Object, Object)`. Use sasit filters instead.
- The client log looks clean for an unrelated reason (the relauncher's log setup), so hunt noise in the server log.
- Stuff A Sock In It must stay on the server (it is not a sound mod).
- Filtered on purpose (harmless, no pack-side lever): mip-level texture size warnings, LoliASM pool clearing, CoFH World's `metadata` deprecation, Fluidlogged API's auto-downloaded whitelists naming absent blocks, Deep Mob Learning's missing `trial` defaults, VintageFix sprite-preload and resource-listing chatter, Gendustry's built-in butterfly Liquid DNA recipes (Forestry's butterflies are off), Compact Machines' example recipes, Railcraft's cart-substitution chatter, Railcraft's skipped `post_metal` / `post_metal_platform` "unpainted + dye" recipes (`EnumPost.METAL_UNPAINTED.getStack()` comes back empty in 12.1 beta; `scripts/mods/railcraft.zs` adds Rolling Machine/crafting recipes for `post_metal:15` and `post_metal_platform:15`, and Railcraft's any-colour + dye recipes still register).
- Left visible on purpose, because they point at something that is really broken: VintageFix `Error retrieving model … for UCW` and other model-loading errors, missing sound files, Twilight Delight's `ModelBakeEvent` exception. Don't filter these until they're fixed or ruled harmless.
