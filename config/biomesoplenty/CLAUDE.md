# Biomes O'Plenty config

`config/biomesoplenty/biomes/defaults/**` is **regenerated and deleted by BOP on every boot**; edits there are lost. Persistent per-biome overrides go in `config/biomesoplenty/biomes/<namespace>/<biome>.json` (same structure without `defaults`), as partial JSON: only the keys to change, BOP falls back to its built-in defaults for the rest.
